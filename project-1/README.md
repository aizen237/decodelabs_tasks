# Store — Responsive Landing Page

A single-page responsive online store landing page built with vanilla HTML, CSS, and JavaScript — no frameworks.

## Features
- Mobile-first responsive layout using CSS Grid and Flexbox
- Breakpoints at 768px (tablet) and 1024px (desktop)
- Fluid typography with `clamp()`
- 
- Semantic HTML5 for accessibility and SEO
- Interactive mobile navigation menu
- Add-to-cart counter
- Newsletter signup with email validation

## Built With
- HTML5
- CSS3 (Grid, Flexbox)
- Vanilla JavaScript

## Sections
- Header with responsive navigation
- Hero
- Featured products grid
- Features strip
- Newsletter signup
- Footer
